## 📌 Sobre o Projeto

Este projeto foi desenvolvido para atender uma das maiores dores de pequenos e médios estabelecimentos gastronômicos: **receber pedidos organizados de forma direta pelo WhatsApp sem depender de taxas de plataformas de terceiros**.

O sistema conta com um visual *Dark Mode* moderno, carregamento rápido e uma experiência de uso pensada prioritariamente para dispositivos móveis (*Mobile First*).

🔗 **Link do Projeto Ao Vivo:** [https://danielribeiro273.github.io/menuhamburgueria](https://danielribeiro273.github.io/menuhamburgueria)

---

## ✨ Funcionalidades

* **Filtro de Categorias em Tempo Real:** Navegação simplificada entre Hambúrgueres, Porções e Bebidas.
* **Carrinho de Compras Interativo:** Adição, remoção e ajuste de quantidades com atualização instantânea do valor total.
* **Badge Dinâmica:** Contador de itens visível no topo da tela.
* **Checkout Inteligente:** Formulário simples para nome e endereço de entrega.
* **Envio Automatizado via WhatsApp:** Gera uma mensagem perfeitamente formatada com o resumo do pedido e envia direto para o estabelecimento.
* **Design Responsivo (Mobile First):** Layout adaptado para uso em smartphones e tablets.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica e acessível.
* **Tailwind CSS:** Estilização moderna e responsiva via CDN.
* **JavaScript (ES6+):** Lógica do carrinho de compras, manipulação do DOM e integração com o WhatsApp.
* **Font Awesome & Google Fonts:** Ícones e tipografia personalizada (*Plus Jakarta Sans*).
